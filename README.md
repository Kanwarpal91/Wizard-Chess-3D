# ♟️ Wizard Chess 3D

**Enter a magical world of chess!** 🧙‍♂️♟️

Wizard Chess 3D is a fantasy-inspired 3D chess game that reimagines classic chess with an immersive visual experience, interactive camera controls, and multiplayer features.

## ✨ Features

- 🎮 **3D Chess Experience** — Explore chess in a 3D environment.
- 📷 **Camera Controls** — View the chessboard from different angles.
- ♟️ **Local Gameplay** — Play chess locally.
- 🌐 **Multiplayer Rooms** — Create or join rooms using WebSockets.
- 💬 **Chat Interface** — A room-based chat interface for multiplayer sessions.
- 🎨 **Modern UI** — An interactive interface built with React.
- 📱 **Responsive Design Goals** — Designed for further refinement across desktop and mobile devices.

## 🛠️ Built With

- React
- TypeScript
- JavaScript
- Three.js

- WebSockets

## 🚀 Installation & Setup

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
```

Replace the placeholders with your actual GitHub repository URL and project folder name.

### Step 2: Install Dependencies

```bash
npm install
```

### Step 3: Start the Development Server

```bash
npm run dev
```

Follow the terminal instructions to open the application locally. If the command fails, check the scripts in `package.json`.
